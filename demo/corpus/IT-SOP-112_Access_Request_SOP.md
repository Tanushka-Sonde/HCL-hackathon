> SYNTHETIC DEMO DOCUMENT. Orion Synthetic Industries (OSI) is fictional.

## 1. Scope

This standard operating procedure explains how employees and contractors request access to OSI systems. All access requires enrollment in multi-factor authentication (MFA) before it is granted.

## 2. Access Request Codes

Access request code ACR-1004 covers VPN access for contractors. It requires approval from the hiring manager, and access expires automatically on the contract end date.

Access request code ACR-2291 covers read-only access to the production analytics database (Atlas Warehouse). It requires approval from the data owner and from the Information Security team (ISEC), and the access expires after 90 days.

Access request code ACR-3310 covers administrator (root) access to production servers. It requires approval from the CISO and is granted for a maximum of 24 hours as break-glass access.

## 3. How to Submit a Request

Requests are submitted in the ServiceDesk portal by selecting the access request code. The service level agreement (SLA) for completing a standard request is 3 business days. Requests without a business justification are rejected.

## 4. Access Reviews

Managers review the access of their team members every quarter. Access that is no longer needed must be revoked within 5 business days of the review.
