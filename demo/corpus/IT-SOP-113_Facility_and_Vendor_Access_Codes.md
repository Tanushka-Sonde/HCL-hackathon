## 1. Scope

This procedure lists access request codes for physical facilities and for external vendors. System access codes for employees are in the Access Request SOP (IT-SOP-112).

## 2. Facility and Vendor Codes

Access request code ACR-2219 covers badge access to the primary data center in Pune. It requires approval from the Facilities Security lead, and badges are reissued every 180 days.

Access request code ACR-3301 covers temporary VPN access for hardware vendors during maintenance windows. It requires approval from the IT Operations duty manager and is limited to 8 hours per window.

Access request code ACR-4410 covers visitor parking permits. It is approved by reception and is valid for one day.

## 3. Lost Badges

A lost badge must be reported to Facilities Security within 4 hours. The old badge is disabled immediately and a replacement fee of USD 25 applies after the second loss in a year.
